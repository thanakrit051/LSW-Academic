# LSW Academic · ระบบฝึกข้อสอบระดับชาติ

หน้าเว็บของระบบฝึกข้อสอบระดับชาติ โรงเรียนหล่มสักวิทยาคม (GitHub Pages)
ข้อมูลทั้งหมดอยู่ใน Google Sheets ของโรงเรียน หน้าเว็บเรียกผ่าน Google Apps Script

- นักเรียน: `https://lsw-academic.github.io/LSW-Academic/`
- ครู: `?page=teacher`
- ผู้ดูแลระบบ: `?page=admin`

ไฟล์ต้นฉบับแก้ที่ `ระบบจริง/Index.html` ในโฟลเดอร์งานของโรงเรียน แล้วคัดลอกมาเป็น `index.html` ที่นี่

รูปโจทย์ข้อสอบย้อนหลังอยู่ใน `img/` (สร้างอัตโนมัติโดย `ข้อสอบย้อนหลัง/เครื่องมือแปลง/make.py` จากรูปต้นฉบับ ห้ามแก้ที่นี่)
