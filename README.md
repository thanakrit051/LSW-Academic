# LSW Academic · ระบบฝึกข้อสอบระดับชาติ

หน้าเว็บของระบบฝึกข้อสอบระดับชาติ โรงเรียนหล่มสักวิทยาคม (GitHub Pages)
ข้อมูลทั้งหมดอยู่ใน Google Sheets ของโรงเรียน หน้าเว็บเรียกผ่าน Google Apps Script

- นักเรียน: `https://thanakrit051.github.io/LSW-Academic/`
- ครู: `?page=teacher`
- ผู้ดูแลระบบ: `?page=admin`
